# Music

Drop a file here and it replaces that track's synthesised version on the next
load. Nothing else has to change — the same crossfade, the same ducking, and if
a file is missing the synth is still playing underneath.

    audio/menu.ogg      (or .mp3)     the title and pause screens
    audio/town.ogg                    Scoria
    audio/combat.ogg                  the wood, the undercroft, the bosses

Loop points are not honoured — the file is looped end to end, so pick or trim
tracks that already loop cleanly.

## Where to get tracks

These are the sources worth using, in the order I would try them. All three let
you filter to **CC0 / public domain**, which is the only licence that needs no
attribution file and no thinking about later:

- **freesound.org** — filter by License: Creative Commons 0. Deep, uneven,
  best for drones and ambience.
- **opengameart.org** — filter by Art Type: Music, License: CC0. Written for
  games, so the loops usually loop.
- **incompetech.com** (Kevin MacLeod) — CC-BY, not CC0. Excellent quality but
  you must credit him in the game; if you use these, put the attribution in the
  settings screen before shipping.

What fits: for `town`, something slow, modal and nearly empty. For `combat`,
percussion-led with a real pulse — the synth version is deliberately restrained
because it has to sit under the windup tone, which is the one sound in this
game that is load-bearing. Check that whatever you pick does not mask it.
